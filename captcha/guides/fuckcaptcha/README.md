# FuckCaptcha field guides

A field guide to 39 CAPTCHA types: one Markdown guide per CAPTCHA type (37 files in captchas/), plus solvers.md (free and open-source solver tools, and paid API services) and resources.md (articles, papers and vendor documentation).

Source: FuckCaptcha (referred to as @fcukcaptcha) by @vsmutok — https://github.com/vsmutok/FuckCaptcha — cloned at commit 410c4cabfc5f8c624cfec0dcf8df51d11ca008f4.

What was imported, and what was not: only the 39 Markdown guides from the upstream docs/ folder, copied verbatim, plus the upstream LICENSE. No code, images, stylesheets or site files were imported. Each per-CAPTCHA guide carries a header image that points at the upstream assets folder, so the logos do not render from this copy — they are visible on the upstream live field guide at https://vsmutok.github.io/FuckCaptcha/ or in the upstream repository. The internal cross-links between the guides (for example the links to solvers.md) still resolve, because the upstream docs/ layout was preserved under this directory.

Intended use: education and authorised research, as the upstream project states — not evading protections on services without permission.
